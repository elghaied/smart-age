# Product Overview

This is a multilingual website template built with Payload CMS and Next.js, designed for content-driven websites, blogs, and portfolios. The project supports both English and Arabic languages with RTL support.

## Key Features

- **Content Management**: Full-featured CMS with Payload for managing pages, posts, media, and site settings
- **Multilingual Support**: Built-in internationalization with English and Arabic support, including RTL layout
- **Layout Builder**: Flexible block-based content system with pre-built components (Hero, Content, Media, CTA, Archive, Forms)
- **SEO Optimized**: Integrated SEO plugin with meta fields, sitemaps, and social media optimization
- **Draft & Live Preview**: Content preview system with draft management and scheduled publishing
- **Search Functionality**: Built-in search capabilities across content
- **Form Builder**: Dynamic form creation and handling
- **Media Management**: Advanced media handling with image optimization and focal point selection

## Content Types

- **Pages**: Static pages with layout builder
- **Posts**: Blog posts and articles with categories
- **Media**: Images, videos, and file uploads
- **Categories**: Taxonomies for organizing content
- **Users**: Admin users with authentication
- **Custom Collections**: Values, Services, Projects, Goals, Features

## Target Use Cases

- Corporate websites
- Blogs and content publications
- Portfolios
- Small to enterprise-grade websites
- Multilingual content platforms
